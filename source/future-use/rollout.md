# Archived draft: RCC transition announcement

> **Status:** retained for future planning only. This text is not part of the
> current ClusterDocs NG user journey and must not be published without a new
> operational review.

The draft described planned changes to login routing, SSH server-identity
verification, browser-based project data transfer, central service reliability,
and protected project websites. It also proposed a portable “RCC Connect” kit,
a final rollout date, and a published host-CA fingerprint.

Before reusing any part of this announcement, confirm the actual delivery
method, support route, dates, service URLs, host identity, and user migration
steps with the responsible service owners. Users should never be instructed to
approve an unexpected host identity or delete host records merely to make a
connection work.

# Safe synthetic example bundle

This bundle demonstrates the Class 18 workflow. All rows and values are
invented and must remain synthetic.

Files:

- [`QUESTION.md`](QUESTION.md) — the result wanted;
- [`example.csv`](example.csv) — invented rows with representative structure;
- [`EXPECTED_OUTPUT.md`](EXPECTED_OUTPUT.md) — a simple acceptance description;
- [`PROMPT.txt`](PROMPT.txt) — a bounded prompt for an external coding agent.

Do not replace this example with copied, shuffled, hashed, or lightly modified
rows from real research data.

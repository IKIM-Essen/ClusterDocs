# You are invited to discover the new RCC

> **ROLLOUT DRAFT — NOT YET LIVE.** This page is prepared for the browser-first release. The public ClusterDocs website has not changed. Follow the instructions only after RCC Services sends an approved personal invitation.

You already have an RCC account. **Your existing SSH key, projects and research data stay in place.** Using the new browser services should not require Linux, SSH or VS Code.

## Your first visit

1. Open the personal invitation sent by **rcc-services**. RCC never asks for your SSH private key or passkey secrets.
2. Confirm ownership of your existing account through the approved verification method. A copied public SSH key alone is not proof of identity.
3. Register a passkey with your device. Use the documented recovery route if you cannot complete the process.
4. Sign in to **My RCC** and select an existing authorized project. If the project is missing, **do not register a second identity**; contact your RCC approver.
5. When enabled, open **Files** for project data, then **Analysis → Notebook** for interactive work or **Workflow** for repeated calculations.

## If you need help

| What happened | What to do |
|---|---|
| Invitation expired or used | Request a new personal invitation from your approver or RCC support |
| Passkey registration fails | Use the approved assisted or recovery path; never send recovery codes by email |
| No project is displayed | Check the signed-in identity and ask the project approver |
| Files or Analysis is unavailable | Continue your existing access; do not move sensitive data to an unrelated location |
| You already use SSH or VS Code | Keep using them when useful; the browser is an easier alternative for common tasks |

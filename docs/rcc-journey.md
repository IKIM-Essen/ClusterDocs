# RCC Journey

!!! info "Optional: explore the physical RCC"
    RCC Journey is a playful, browser-based way to explore the hardware behind
    RCC. It is not required onboarding, and it does not replace ClusterDocs.

RCC Journey connects the physical data centre to the concepts users encounter
when they submit jobs, store data, or use accelerators.

The experience is designed around the real RCC room and rack layout, with
curated photographs, an interactive rack map, short explanations, and guided
stories such as **Follow my Slurm job**.

## What you will be able to explore

- the server-room layout and racks;
- real rack photographs and selected equipment hotspots;
- CPU, GPU, storage, networking, and service-machine roles;
- a playful end-to-end path showing where a Slurm job goes;
- optional deeper technical explanations linked back into ClusterDocs; and
- a short data-centre film when the media set is ready.

## Public-safe by design

RCC Journey is a separate static web application. It receives only a curated,
public-safe export of the private infrastructure map.

Operational data such as management addresses, BMC details, MAC addresses,
management switch identities, sensitive cabling notes, and credentials are not
part of the Journey data model.

ClusterDocs remains the source of truth for mutable RCC technical facts. RCC
Journey is the exploratory layer: use it to understand *what the cluster is*,
then follow the links back here when you need instructions or current policy.

## Relationship to RCC Expedition

- **RCC Expedition** teaches you how to use RCC safely.
- **RCC Journey** lets you explore what the RCC physically is and how the major
  components fit together.

Journey is deliberately optional: there is no requirement to complete it
before using RCC.

The standalone RCC Journey site is currently being built and will be linked
from this page when the first public-safe release is ready.
